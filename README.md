# CatDots: Territory — Privacy Policy

Public, bilingual privacy policy for the Android game **CatDots: Territory** by **Zabastron**.

- Russian + English: [Privacy Policy / Политика конфиденциальности](https://vencedoranton.github.io/catdots-privacy/)
- Support / Поддержка: zabastron@gmail.com

The website is a static copy of the privacy text bundled with the Android app. It contains **no game source code, Android APK/AAB files, private keys, or user data**.

## Publishing

GitHub repository owner must select **Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save**. Check the GitHub Pages deployment status and the public website before adding the URL to Google Play Console.

When privacy practices change, update both this public `index.html` and the app's bundled `app/src/main/assets/privacy.html` in its **private** development repository, keeping the texts aligned. Publishing this site does not publish or release the game itself.
